# 페이지 기획 기준

확정한 구조는 프로필이 먼저 보이는 홈 한 페이지와 사례 상세 세 편이다. 홈은 `/`에서 제공한다. 사례 상세 세 편은 다음 단계다.

```text
홈: 프로필 → 대표 작업 → AI 에이전트와 일하는 방식 → 연락
                └→ 사례 상세 → 대표 작업 목록 복귀
```

- 홈에서는 이름·역할을 먼저 보여주고 방문자가 소개에서 대표 작업으로 바로 갈 수 있게 한다.
- 현재 ‘대표 작업 보기’는 홈의 `#work`로 이동한다. 상세 경로가 준비되면 같은 PR에서 공용 사례 slug로 제목과 상세 페이지를 연결한다.
- 상세 페이지는 맡은 역할, 해결한 문제, 선택한 설계와 결과를 구분한다. 수치에는 비교 조건과 측정의 한계를 붙인다. 공개가 확인된 정보만 사용한다.
- 공용 UI는 외형·접근성을 담당한다. 어느 사례를 열지, 어떤 내용을 보여줄지는 화면이 결정한다.
